# Project illustrations

- architecture.svg / architecture.png: source-to-dashboard architecture.
- tech-stack.svg / tech-stack.png: eight technologies and their roles.
- icons/: original vendor/community SVG artwork, source URLs in icons/SOURCES.json.

SVGs are self-contained, editable and render on GitHub. PNGs are 1920 pixels wide for presentations.

Rebuild SVGs: python scripts/draw_architecture.py

Logo sources: Devicon (MIT), Simple Icons (CC0) and microsoft/PowerBI-Icons. Brand names and marks belong to their respective owners. The illustrations describe this project's use of the technologies, not vendor endorsement.
